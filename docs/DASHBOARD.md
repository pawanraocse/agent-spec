# Control Plane Dashboard — Product Showcase

> **Status:** Shipped (v2.0.0 Control Plane, Phase 2 complete)  
> **Architecture:** React 19 + TypeScript SPA served by stdlib `http.server` loopback; legacy v1 retired (CP-042).  
> **Tasks & Slices:** [`todo-plan.md`](../todo-plan.md) (Slices 5–6c complete).  
> **Strategy & AI-First:** [`MASTER-PLAN.md`](MASTER-PLAN.md) (DEC-15 AI-first observer & governance).  
> **Screen Spec & Overhaul:** [`dashboard_overhaul.md`](../dashboard_overhaul.md).

The dashboard is the **primary governance and observation surface** for the agent harness. CLI tools (`agent-spec-tokens.py`, `graphify-cli`) and hook event spines (`hooks/cursor-event.py`) provide honest, deterministic data; the UI renders ROI, subagent debugging, gate audits, and AST dependency blast radiuses.

---

## Principles (DEC-15 AI-First Aligned)

| Principle | Source & Enforcement |
|-----------|----------------------|
| **Local-first & stdlib backend** | SQLite + stdlib `http.server` on `127.0.0.1`; no cloud telemetry, no PyPI server dependencies (S-003). |
| **AI-First ladder (DEC-15)** | Skill/Rule → Hook → AI Judgement JSON → Thin deterministic code. Code reserved strictly for security, exact computation, per-call latency, or plumbing. |
| **Observer & Prompt Composer** | Cursor chat is the primary agent runtime. Dashboard acts as observer and prompt composer copying slash commands, avoiding headless chat emulator fragility. |
| **Honest by construction** | Provenance badges (`measured`, `estimated`, `demo_seed`, `ai_judged`). Zero invented metrics or hand-coded heuristic evaluations. AI reviews generated by `/agent-spec-session-review`. |
| **Subagent debugging** | First-class subagent waterfall, timeline, and tool execution breakdown. |
| **Proof pack & ROI** | Token savings calculator and export (`agent-spec-platform.py export`) measuring Graphify AST vs naive whole-file reads. |

## Five Workspaces (v2 Control Plane)

1. **Home:** System health status bar (graph freshness, hooks status, doctor check, active background jobs), 7-day sparklines, interactive 5-step guided tour matching `demo.md`.
2. **Sessions:** Context gauge, session intelligence, subagent tree, AST diff inspection, and AI-judged session reviews.
3. **Runs:** SDLC 6-gate audit timeline, step status graph, fail-open nudges, and execution receipts.
4. **Governance:** Deterministic gaps audit (`step_failed`, `run_failed`, `secret_path_blocked`), S-002 security quarantine events, rule violation tracking.
5. **Knowledge:** Bounded memory facts browser, team-fact filtering, interactive AST graph blast radius explorer.

## Architecture (Control Plane v2)

```
Cursor hooks (cursor-event.py) ──► events.jsonl ──► ingest.py ──► SQLite (platform.db)
graphify-build ──────────────────► graph_stats ─────────────►─┘
agent-spec-memory ───────────────► memory_facts ────────────►─┘
pipeline STATE.json ─────────────► gate_events ─────────────►─┘
AI reviews (*.json) ─────────────► reviews/ ────────────────►─┘
                                                              │
                                                              ▼
                                              stdlib http.server (127.0.0.1)
                                                              │
                                                              ▼
                                              React 19 SPA (ui/dist/)
```

**Start:**
```bash
python3 bin/agent-spec-platform.py ingest
python3 bin/agent-spec-platform.py serve
```

Build the frontend bundle (stays under 400 kB gzip budget; currently ~104 kB):
```bash
(cd ui-src && npm run build)
```
