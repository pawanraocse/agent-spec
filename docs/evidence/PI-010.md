- 2026-11-18 [x] `/api/compare?a=&b=` now uses `bin/aspec_platform/session_compare.py` (a project route) instead of only shelling out to `agent-spec-tokens.py compare`. Each side shows the following:
  - tokens from response spans;
  - the outcome signals from `signals.for_trace`, added up across the session: requests, tool calls, failures, files edited, requests verified after their last edit, files reworked later, guard blocks, subagents and compactions;
  - quality: the `agent-spec-session-review` overall score and each dimension score (`ai_judged`);
  - context: digest bytes and the injected facts from `injections.jsonl` (`measured`), plus the skills used.

  The response also has the a − b delta and, when both sessions have transcripts, the token tool's text. Missing data is `None` and shows as a dash, never as 0. A malformed or unknown id returns 404. The UI is `ui-src/src/features/SessionCompare.tsx` on Sessions → A/B Compare. Every figure renders through `<Num>`; the vitest honesty check covers it, and review scores are marked AI-judged. The old UI read `delta_tokens`, which the API never returned, so it always showed 0. Tests: tests/test_session_compare.py (4), tests/test_savings.py compare cases, vitest 28 passed, tsc clean.
