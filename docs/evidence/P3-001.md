# P3-001 evidence (2026-11-13, partial)

The design is the LLD addendum in `docs/IMPLEMENTATION-GUIDE.md` ("LLD addendum — P3-001").

## Built

- `bin/graphify-mesh.py add | remove | build [--refresh] | stats [--json]`. The hub keeps
  `.agent-spec/mesh.json` (`{repo_id, path, graph_sha, updated}`) and one graph per member
  under `.agent-spec/mesh/<repo_id>/`. The merged graph goes to
  `.agent-spec/graph/mesh-graph.json`, with node ids of the form `<repo_id>:<path>`.
- `graphify-build.py --out DIR` builds a member's graph without writing to the member repo.
  Graph 5.1 adds `unresolved_imports`. It skips platform namespaces, file names such as
  `AtlBase.h`, wildcards, and tokens with fewer than two segments.
- A cross-repo edge forms only on an exact qualified name. For Java and Kotlin that is the
  FQN after the first source root; for Python it is the module path from the topmost
  package. A name defined in two or more repos becomes `imports_ambiguous`.
- `install.sh` ships `graphify-mesh.py`. The `agent-spec-query-graph` skill explains how to
  read the mesh, so cross-repo questions stay a skill's job.

## Verified

- `python3 -m unittest tests.test_graph_mesh`: 7 tests OK. In the fixture, three repos
  (`lib`, `svc`, `web`) form one component. A path suffix such as `lib.Strings` does not
  link. A shared FQN is reported as ambiguous.
- Regressions: `tests.test_graph_symbols`, `tests.test_ingest_graph` and
  `tests.test_blast_radius` give 23 OK, and `bin/agent-spec-selftest.sh` ends with "All
  selftests passed.".

## Real repositories (names withheld: this repository must not name others)

Ten local repositories built into a scratch hub: 16,113 nodes, 0 cross-repo `imports`
edges, 0 ambiguous. Manual checks agree that this is correct, not a miss:

- The one candidate imported `*.autogenerated.*` classes that exist in no member's source.
- No member declares another as a Gradle or Maven dependency.

Whatever couples these repositories goes over HTTP or a message broker. That is P3-002, and
it is what can satisfy "≥3 repos in a connected graph" on this machine.
