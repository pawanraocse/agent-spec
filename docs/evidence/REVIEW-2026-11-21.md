# End-to-end review — 2026-11-21

Scope: whether agent-spec saves tokens and improves efficiency in Cursor, whether it helps on
both short prompts and long conversations, and whether the graph, self-learning, cross-session
memory and the RAG database work. Every number below was measured in this session on this
repository unless it says otherwise.

## Defects found and fixed

1. **Graph `context` ignored symbols** (`bin/graphify-cli.py`). The command the digest pushes on
   every code task could not find a file by the functions in it. To reproduce the measurement,
   run `python3 evals/graph_context_eval.py`.
2. **Memory search was a substring match** (`bin/agent-spec-memory.py`).
3. **Warm resume never parsed real snapshots** (`bin/agent-spec-digest.py`,
   `skills/agent-spec-snapshot/SKILL.md`). The parser wanted `### Open` and
   `### Load next session` headings that the snapshot skill never asked for.
4. **The digest forbade the snapshot while carrying only its title.** In the bench, two
   harness chats out of two answered "from the previous chat" questions with "I can't see that
   earlier chat" and got them wrong.
5. **Recall false positives** (`bin/agent-spec-recall.py`): path tokens and one-word overlaps.
6. **The receipt counted a guidance line as a remembered fact** (`bin/agent-spec-receipt.py`).
7. **RAG result lists dominated by one file** (`bin/aspec_platform/retrieval.py`).
8. **The selftest failed on `CURSOR.md`**, because the uncommitted trim had removed the only
   mention of `sessionStart`.
9. **Stale vendor-name markers** in three memory facts, `CONSTITUTION.md` and `PROJECT-INDEX.md`.
10. **A bench grader bug.** `views-blast` turn 2 expected `impact.py`, but correct answers say
    `impact`.
11. **The dashboard's empty-index hint** named a non-existent `ingest --what` flag.

Each code fix has a regression test: `tests/test_graph_symbols.py::ContextRankingTest`,
`tests/test_memory.py::test_search_*`, `tests/test_recall.py::test_paths_and_single_shared_words_do_not_match`
and `tests/test_retrieval.py::DiversifyTest`. The existing digest and receipt tests cover the
parser and the counter.

## Open — needs a decision or a run

- **Memory is over its cap**: 91 facts against 40, and `INDEX.md` is 9523 B against 8000. The
  doctor's suggested fix, an age-based prune at 51 days, would delete load-bearing decisions
  such as "graph storage stays committed JSON" and "cost not tokens". Prune by relevance
  instead (superseded, duplicated, or never matched), and only with the owner's approval.
- **The installed skills on this machine are older than the repository.** `~/.cursor/skills`
  still holds `.algosec-agent-spec-*` markers and skill bodies that read them. Re-run
  `./install.sh` from the clone so the installed skills, and the `.agent-spec-root` marker the
  current code reads, match.
- **The graph is still under-used**: 4 graph calls across every harness turn in the interim
  bench. Re-run the bench with this session's ranking before deciding whether the preToolUse
  hook should steer repo-wide greps to the graph. A redirect costs an extra round trip when
  the grep was the right tool.
- **The experience store holds only hook-probe sessions.** Experiences are written by the
  Cursor `stop`/`sessionEnd` hooks. Work done in Claude Code records none, by design (Cursor
  only in Phase 1).
- **`test_ingest_transcripts` performance assert is timing-sensitive.** It took 4.46 s once
  while every gate ran on the same machine, and 0.05 s alone, against a 2 s limit.
