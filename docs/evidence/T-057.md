# T-057 — Live hook verification (DEBT-005)

Run on 2026-11-13 with `cursor-agent` 2026.11.11 (`--print --trust --model auto`) in this
repository, with `AGENT_SPEC_HOOK_DEBUG=1` so the hook logged the shape of each payload and its
decision to `$TMPDIR/algosec-agent-spec-hook-debug.jsonl`.

## What Cursor sends

| What the model called (agent transcript) | What `preToolUse` received (`tool_input`) |
|---|---|
| `Read {"path", "offset": 1, "limit": 40}` | `{"file_path"}` |
| `Read {"path"}` | `{"file_path"}` |
| `StrReplace {"path", "old_string", "new_string"}` | `Write {"file_path", "content"}`, with the whole new file as content |

Cursor rewrites these calls before the hook runs. As a result, a ranged read looks the same
as a whole-file read, and a targeted edit looks the same as a full rewrite. The old suspicion
that a range key was missing from `RANGE_KEYS` was wrong: no range key arrives at all.

The agent transcript does record the real arguments, but it is no fallback. Cursor writes it
after the tool runs, so at hook time it is one message behind. A version that read it was tried
and reverted. It still denied ranged reads, and it allowed a whole-file read by matching it to
an earlier ranged read of the same file.

`postToolUse` for a Read does report what came back: `tool_output` is
`{"file_path", "content_length"}`, and `content_length` tracks the file size closely
(2744 for a 2754 B file).

## Decision: follow Cursor's harness

- `hooks/cursor-pre-tool-use.py`: when the payload carries `cursor_version`, a Read without a
  range key and a Write without `old_string` are allowed (`allow-unobservable`). The rangeless
  read nudge, the hard cap (`AGENT_SPEC_READ_HARD_CAP_KB`) and the rewrite nudge still apply to
  payloads from other harnesses.
- `hooks/cursor-event.py`: a Read with no range key is judged afterwards. The spine row gets
  `read_chars` (from `content_length`) and `file_bytes`, and `ranged` is false only when the read
  returned at least 90% of the file. Coach › Whole-file reads therefore counts real whole reads
  under Cursor, where before it counted every Cursor Read.

## Live results after the fix

| Call | Hook decision | Spine row |
|---|---|---|
| Read `todo-plan.md`, offset 1, limit 40 | allow-unobservable | `ranged: true`, 2912 of 56696 B |
| Read `docs/IMPLEMENTATION-GUIDE.md`, whole | allow-unobservable | `ranged: false`, 73888 of 74292 B |
| StrReplace on a 4840 B scratch file | allow-unobservable | edit applied |

Before the fix, the same ranged read and the same StrReplace were both denied with
"algosec-agent-spec input discipline".
