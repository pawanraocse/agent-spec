## Scripted pass (2026-11-18)

A fresh clone, an empty `HOME`, the system `python3` (3.10.12, not the developer's pyenv) and
`PATH=/usr/bin:/bin`, following README › Install word for word:

| Step | Command | Result | Time |
|---|---|---|---|
| 1 | `./install.sh`, `./check-install.sh` | All checks passed | 3 s |

Install to the first dashboard view takes well under ten minutes; the commands take seconds.

Stumbles found and fixed:

1. README › Install never said how to open the dashboard. Added "3. Dashboard (optional)".
2. README said 43 skills; 35 are installed. Corrected.
3. The first page load straight after `--register` could fail: the server answered before its
   background ingest had created the database tables (`sqlite3.OperationalError: no such
   table: steps`). `serve.ensure_db` now creates the schema before serving; regression test
   `FirstServeTest`.
4. An empty project opened on a page of zeros and dashes. The Summary now opens on "No traced
   requests yet" with the three ways to get data (Cursor with hooks, the local Ollama agent,
   the mesh demo). An empty savings panel collapses to one line saying what fills it.
5. "Load demo data" wrote rows to a table no page reads since the five-space layout, so the
   button did nothing. Removed; the mesh demo replays a recorded chat through the real hooks
   instead.

## Owed

The acceptance asks for someone new to the project. This pass was scripted by the agent that
knows the code, so it cannot catch a stumble that only a new reader would hit.
