# H-005 — injected facts on the Impact tab

## 2026-11-18 — recorded-hook replay

The recorded Cursor `sessionStart` payload (`tests/fixtures/hooks/recorded/`) replayed through
the installed hook in a freshly registered project (`demo-setup.sh`) wrote no
`metrics/injections.jsonl` row, so the Impact tab of that conversation listed no facts.
Cause: `record_injection` returned early when `.agent-spec/metrics/` did not exist yet, which
is the state of every project before its first hook writes there. Fixed in
`hooks/cursor-session-start.py`; the replayed conversation's Impact tab now lists
"routes are a public contract" with 819 digest bytes (`demo-dryrun.py`, impact beat).

Owed: the same check in one live Cursor chat.
