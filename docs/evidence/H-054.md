# H-054 — Live test matrix on local models

## 2026-11-19 — first runs

`bin/agent-spec-livetest.py --full --models all` on WSL2 (Python 3.12.2), Ollama on the Windows
host at `http://172.28.32.1:11434`, chat models `qwen2.5-coder:14b`, `qwen2.5-coder:7b` and
`qwen3:4b`, embeddings `nomic-embed-text`. Each run installs into a temporary HOME and builds the
mesh demo fresh; nothing is mocked. The method is in [docs/LIVE-TESTING.md](../LIVE-TESTING.md).

### Defects the live runs found, all fixed

| # | Found by | Defect | Fix |
|---|---|---|---|
| 1 | L12 | In a registered project, the dashboard Agent Console was off even with Ollama running. `install.sh` never copied `agent-spec-ollama-agent.py` into `.agent-spec/bin`, and `agent_exec.OLLAMA_AGENT` resolves it there, so `console_status()` reported `enabled: false`. The Console only ever worked when the dashboard was served from the package clone. | `install.sh` installs the Ollama agent, `agent-spec-bench.py`, `agent-spec-live.py` and `agent-spec-livetest.py` with the other platform entry points. |
| 2 | L10 (security) | The Ollama agent's `--resume` history (`~/.cache/agent-spec/ollama-chats/<conversation>.json`) kept prompts and tool output in clear: a pasted AWS key id and GitHub token, and the `.env` canary that the bare arm had read. | History is written through `redact.redact_obj`, created `0600`. Unit test `test_chat_history_is_redacted_and_private`. |
| 3 | L11 (security) | `--bare` (the A/B baseline) skipped `preToolUse` entirely, so the secret quarantine was off as well: the baseline read `.env` and sent the secret to the model. | `--bare` still fires `preToolUse` and honours only the quarantine's deny; the input-discipline guard stays off, so the benchmark baseline is unchanged. Unit test `test_bare_arm_keeps_the_secret_quarantine`. |
| 4 | L07 on 14b | `qwen2.5-coder:14b` writes several tool calls as JSON lines in the message text. The parser took one greedy `{.*}` match, failed to decode two objects, and returned the raw JSON as the answer. | `text_tool_calls` decodes every object naming a known tool. Unit test `test_several_text_tool_calls_all_run`; L07 on 14b now passes. |

Also changed: the agent's system prompt said "Answer with the file path", so a two-part question
("which file, and who consumes it") lost its second half in the first manual run. It now says
"Answer every part of the question, naming each file path".

## Recommendations not done here

1. **Queue Console jobs per Ollama endpoint.** L15 shows Ollama serves concurrent chats one at a
   time (238 s for the slowest of three on 7b). The Console accepts parallel jobs, so a second
   user waits with no feedback; show a queue position or cap jobs at `OLLAMA_NUM_PARALLEL`.
2. **Retry the final answer when it is only tool-call JSON.** Defect 4's parser fix covers mid-loop
   steps; the tool-free final step can still return call JSON from a stubborn model.
3. **Run the smoke tier in CI.** `--only L01,L02,L03,L04,L05,L16` needs no model (L01 skips) and
   takes about 10 s; it would have caught defect 1.
