# Acknowledgements

**agent-spec** was independently designed and written from scratch.

The concept of spec-driven development as a structured methodology was partly inspired by [github/spec-kit](https://github.com/github/spec-kit) (MIT License © GitHub, Inc.) — an open-source toolkit for spec-driven development. No files, content, or code from spec-kit were copied into this project.

The ideas in agent-spec draw on decades of software engineering wisdom:

- **Clean Architecture** — Robert C. Martin (Uncle Bob)
- **SOLID Principles** — Robert C. Martin
- **Domain-Driven Design** — Eric Evans
- **The Pragmatic Programmer** — David Thomas & Andrew Hunt
- **Accelerate** — Nicole Forsgren, Jez Humble, Gene Kim
- **Test-Driven Development** — Kent Beck
- **Atomic Habits** (applied to dev workflow) — James Clear
